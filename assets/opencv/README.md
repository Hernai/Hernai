# OpenCV.js Assets

Esta carpeta debe contener:

## Archivos requeridos:
- `opencv.js` - OpenCV.js main library
- `opencv.wasm` - WebAssembly binary

## Descarga:
```bash
# Opción 1: Desde releases oficiales
wget https://docs.opencv.org/4.x/opencv.js -O opencv.js

# Opción 2: Desde CDN (agregar en HTML)
<script src="https://docs.opencv.org/4.x/opencv.js"></script>
```

## Nota:
El proyecto puede funcionar cargando OpenCV.js desde CDN si los archivos locales no están presentes.
