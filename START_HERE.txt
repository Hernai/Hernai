🐛 SOLUCIÓN DE PROBLEMAS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    ❌ No carga la página
       → Verifica que el servidor esté corriendo
       → Asegúrate de usar http://localhost:8000
       → Prueba en modo incógnito

    ❌ "Error al inicializar"
       → Verifica conexión a internet (primera vez)
       → Recarga la página (Ctrl + F5)
       → Abre consola (F12) para ver errores

    ❌ "No se detecta INE"
       → Asegúrate que sean fotos de INE reales
       → Verifica que ambas imágenes estén cargadas
       → Mejora iluminación de las fotos

    ❌ "Baja confianza OCR"
       → Toma fotos con mejor iluminación
       → Enfoca bien la credencial
       → Evita sombras y reflejos
